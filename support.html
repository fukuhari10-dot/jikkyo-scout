このアプリについて

非公式のファンアプリです

ヤキュトモは、ヤキュトモ運営事務局が運営する非公式のファンアプリです。野球ゲームの開発・運営会社（株式会社コナミデジタルエンタテインメント）、YouTube（Google LLC）、一般社団法人日本野球機構および各球団とは関係がなく、承認や協賛を受けたものではありません。

ゲームの名前、球団名、選手名などは、それぞれの権利者の商標または登録商標です。このアプリでは説明のために文字で書くことがありますが、ロゴやゲームの画像は使っていません。

データの出典

チャンネル・配信者の名前、登録者数、動画のタイトル・再生回数・サムネイル、ライブの同時視聴者数は、YouTube API サービスを使って YouTube から取得した公開情報です。数値は YouTube の公開値をそのまま表示しています（1,000人以上の登録者数は YouTube 側で上3桁に丸められています）。

応援票・ポイント・ランキング・球団対抗・「みんな」の投稿・ガチャ報告は、このアプリの利用者によるもので、YouTube のデータではありません。試合日程は NPB 公式サイトの公開情報（日時・対戦・球場）をもとに作っています。

掲載について

載っているのは、野球ゲームの動画・配信をしている YouTube チャンネルと、プロ野球の球団ファンとして動画を出している YouTube チャンネルの公開情報だけです。表示する動画・ライブは、野球ゲームまたはプロ野球に関するものだけです。球団・リーグ・テレビ局などの公式チャンネルは載せていません。掲載をやめたい配信者の方は「お問い合わせ・掲載の停止」からご連絡ください。確認のうえ、すみやかに削除します。
