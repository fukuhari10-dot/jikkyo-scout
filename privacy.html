プライバシーポリシー

サポート利用規約プライバシーポリシー特定商取引法に基づく表記

最終更新：2026年10月（版 2026-10）

1. 取得する情報

  • ニックネーム、応援球団、好きなジャンル
  • アプリ内の操作の記録（応援票、スカウト、投票、ポイント、ミッション、フォロー）
  • 「みんな」への投稿（文章・つけた画像・球団や試合のタグ）・返信、実況の書き込み、リアクション・募集への参加・「参考になった」・通報・ブロックの内容。画像は送る前に端末の中で小さくし、撮影場所などの写真の情報は消してから送ります
  • 観戦仲間：フォローした人の一覧と、「参加中の実況を観戦仲間に見せる」をオンにした人の、いま入っている実況ルーム（最後の確認から5分で消え、過去の記録は残しません。初めはオフです）
  • Apple・Google でサインインしたときの識別子（メールアドレスは取得しません）
  • 端末や通信の情報（不正防止のための確認情報をふくむ）
  • スカウトパスの購入状況（Apple・RevenueCat から）
  • 広告の配信・効果測定のための情報（広告識別子は、あなたが許可した場合だけ）
  • アプリの使い方の記録（開いた画面・使った機能・アプリのバージョン・不具合の情報）。書いた文章や検索した言葉はふくみません。マイ →「使い方データの送信」でオフにできます
  • ご意見・要望フォームに書いた内容

2. 使う目的

本アプリの提供（ランキング・「みんな」など）、不正やいやがらせの防止、お問い合わせへの対応、機能の改善（使い方の記録を集計して、使いにくいところを見つける。集計や分析にAIを使うことがあります）、広告の表示、購入の管理のために使います。

3. YouTube API サービス

本アプリは、配信者や動画の公開情報を表示するために YouTube API サービスを使っています。利用者の YouTube や Google のアカウントにはアクセスしません。Google のプライバシーポリシー：https://policies.google.com/privacy。Google アカウントの接続の管理：https://security.google.com/settings/security/permissions

4. 外部への送信（利用者情報の外部送信）

  • Google LLC（Firebase）：ログイン、データの保存、不正防止、使い方の分析（Google Analytics for Firebase）のため。識別子・操作の記録・投稿
  • Google LLC（AdMob）：広告の配信・報酬の確認のため。広告識別子（許可した場合）・端末情報
  • RevenueCat, Inc.：サブスクリプションの管理のため。購入状況・識別子
  • Apple Inc.：サインイン・購入のため

5. 第三者への提供

法令にもとづく場合を除き、本人の同意なく第三者に個人情報を提供しません。上記の委託先には、目的の範囲内で必要な情報を渡します。

6. 保存期間と削除

アカウントがあるあいだ保存します（配信・試合の実況の書き込みは7日で自動で消えます。参加中の実況ルームの記録は5分で消えます）。今日の応援カードの画像は端末の中で作り、サーバーには送りません。マイ →「アカウントを削除」から、いつでも削除できます。削除すると、ポイント・スカウト・設定は消え、投稿は「退会したユーザー」として見えなくなります。
